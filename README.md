# 職能治療團體活動資料庫 (OT Group Activity Wiki)

> 一個以 **Andrej Karpathy LLM Wiki** 架構打造的職能治療團體活動持久型知識庫。  
> 完整收錄 **26 篇** 來自臨床教學與醫院病房的真實職能治療團體活動計畫書，涵蓋 **兒童職能**、**精神科病房**、**社區精神復健** 與 **高齡長照** 四大領域，結合《戀與深空》沈星回「星河紫」暖色調設計系統。

---

## 🌟 專案簡介

在臨床職能治療（Occupational Therapy）中，活動分析（Activity Analysis）與分級調適（Grading & Adaptation）是核心專業能力。然而治療師的教案常常散落在紙本、Word、PDF 或筆記中，缺乏系統性的串接與累積。

本專案不同於單純的「單頁網頁製作（Vibe Coding）」，而是落實了 **持久型知識庫（Compounding Knowledge Base）** 的概念：
1. **建立專案規則（AGENTS.md）**：嚴格定義檔案結構、活動 Schema、命名規範與 AI Ingest / Query / Lint 工作流。
2. **AI 主動維護與複利累積**：AI 代理人消化收錄了 `sources/` 資料夾內的 **22 份真實臨床 PDF 計畫書**，自動解析提取出標準活動頁、建立雙向連結（Backlinks）、維護全站總目錄（`index.md`）與演進日誌（`log.md`）。
3. **公開可瀏覽的現代化成果網頁**：依據沈星回官方代表色「星河紫」搭配星光暖金設計，支援 GitHub Pages 即時瀏覽，提供四大族群切換、關鍵字即時檢索、與高對比顯示「分級調適（Grading Down / Up）」及「安全注意事項」的詳細分析視窗。

```text
├── AGENTS.md                  # [核心規章] AI 與治療師協同開發維護之最高準則
├── README.md                  # [專案說明] 本說明文件

└── wiki/                      # [持久知識庫] AI 擁有並維護之 Markdown 知識網路

    ├── activities/            # [活動標準頁] 26 篇嚴格依據 5 大模組撰寫之 Markdown
    ├── populations/           # [四大族群頁] 兒童、精神科病房、社區復健、高齡長照指引
    └── skills/                # [核心能力頁] 精細動作、感覺調節、執行功能、社交互動
```

## 🤖 專案規則如何幫助 AI 繼續擴充？

在 `AGENTS.md` 的規範下，未來若要新增一個新團體活動（例如：「高齡長照的星夜懷舊拼布團體」），任何接手的 AI 代理人只要閱讀 `AGENTS.md`，就能清楚執行標準 SOP：
1. **結構規範**：嚴格依照規定的 5 大核心模組（設計理念、材料與替代物、流程步驟、Grading Down/Up 分級調適、安全注意事項）輸出在 `wiki/activities/`。
2. **知識串接**：自動在 `wiki/populations/` 和對應的 `wiki/skills/` 補上雙向連結。
3. **目錄與演進同步**：在 `wiki/index.md` 矩陣追加新活動列，並在 `wiki/log.md` 記錄 `[YYYY-MM-DD] ingest | ...`。
4. **前端連動**：同步將 JSON 物件寫入 `data/activities.json`，靜態網頁端（GitHub Pages）無需重新編譯，即可自動渲染出具備卡片篩選、搜尋與彈窗詳情的新活動。
