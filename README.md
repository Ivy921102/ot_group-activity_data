> 一個以 **Andrej Karpathy LLM Wiki** 架構打造的職能治療團體活動持久型知識庫。  
> 完整收錄 **32 篇** 來自臨床教學與醫院病房的真實職能治療團體活動教案（由 **22 份真實臨床 PDF 計畫書** 經活動分析與臨床調適校正而成），涵蓋 **兒童職能**、**精神科急性病房**、**精神科慢性/復健病房**、**精神科日間病房**、**社區精神復健** 與 **高齡長照** 六大領域，並支援 **5 大團體類型** 篩選，結合《戀與深空》沈星回「星河紫」暖色調設計系統。

---

## 🌟 專案簡介

在臨床職能治療（Occupational Therapy, OT）中，活動分析（Activity Analysis）與分級調適（Grading & Adaptation）是核心專業能力。然而治療師的教案常散落在零散的紙本、Word、PDF 或筆記中，缺乏系統性的串接、複利累積與跨族群轉化。

本專案不同於單純的「單頁網頁製作（Vibe Coding）」，而是貫徹了 **持久型知識庫（Compounding Knowledge Base）** 的精神：
1. **建立專案規則（AGENTS.md）**：嚴格定義檔案結構、活動 5 大模組 Schema、命名規範、跨族群標記與 AI Ingest / Query / Lint 工作流。
2. **AI 主動維護與複利累積**：AI 代理人消化收錄了 `sources/` 資料夾內的 **22 份真實臨床 PDF 計畫書**，將其中的複合活動依臨床獨立性拆分與合併，自動生成 32 篇標準活動頁、建立雙向連結（Backlinks）、維護全站總目錄（`wiki/index.md`）與演進日誌（`wiki/log.md`）。
3. **精神科病房三大次族群細分**：因應臨床特性差異，將精神科病房明確區分為**急性病房**（現實導向、最高安全清點）、**慢性/復健病房**（手功能維持、作息延緩退化）與**日間病房**（社交技巧SST、生活獨立銜接）。
4. **適用人數精確核實**：嚴格依據 22 份 PDF 原文載明之目標人數、分組規模或材料備料份數（如 30份底稿、25人份材料包等）逐一核定。
5. **跨族群標籤與符號完全統一**：所有適用的族群皆採用一致之專屬徽章色彩與圖標，全面移除「適用」後綴，呈現專業均一之視覺識別。
6. **公開可瀏覽的現代化成果網頁**：依據沈星回官方代表色「星河紫」搭配星光暖金設計，支援 GitHub Pages 即時瀏覽，提供臨床族群與團體類型雙重維度切換、關鍵字即時檢索，並具備完整展示「分級調適（Grading Down / Up）」及「臨床安全注意事項」的詳細分析抽屜視窗。

## 🚀 成果網頁線上瀏覽與 GitHub 部署教學

### 本地即時預覽：
直接以瀏覽器開啟專案根目錄的 `index.html`，系統內建了完整 32 篇活動的 Fallback 備用資料，無須任何本機伺服器即可離線順暢使用。

### 部署至 GitHub Pages：
1. 將本專案上傳至 GitHub 新儲存庫。
2. 進入儲存庫的 **Settings** -> **Pages**。
3. 在 **Branch** 選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，按下 **Save**。
4. 等待 1~2 分鐘，即可獲得專屬公開線上展示網址（例如：`https://<username>.github.io/<repo-name>/`）。
