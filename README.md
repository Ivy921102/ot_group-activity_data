# 職能治療團體活動資料庫 (OT Group Activity Wiki)

> 一個以 **Andrej Karpathy LLM Wiki** 架構打造的職能治療團體活動持久型知識庫。  
> 完整收錄 **32 篇** 來自臨床教學與醫院病房的真實職能治療團體活動教案（由 **22 份真實臨床 PDF 計畫書** 經活動分析與臨床調適校正而成），涵蓋 **兒童職能**、**精神科病房**、**社區精神復健** 與 **高齡長照** 四大領域，並支援 **5 大團體類型** 篩選，結合《戀與深空》沈星回「星河紫」暖色調設計系統。

---

## 🌟 專案簡介

在臨床職能治療（Occupational Therapy, OT）中，活動分析（Activity Analysis）與分級調適（Grading & Adaptation）是核心專業能力。然而治療師的教案常散落在零散的紙本、Word、PDF 或筆記中，缺乏系統性的串接、複利累積與跨族群轉化。

本專案不同於單純的「單頁網頁製作（Vibe Coding）」，而是貫徹了 **持久型知識庫（Compounding Knowledge Base）** 的精神：
1. **建立專案規則（AGENTS.md）**：嚴格定義檔案結構、活動 5 大模組 Schema、命名規範、跨族群標記與 AI Ingest / Query / Lint 工作流。
2. **AI 主動維護與複利累積**：AI 代理人消化收錄了 `sources/` 資料夾內的 **22 份真實臨床 PDF 計畫書**，將其中的複合活動依臨床獨立性拆分與合併，自動生成 32 篇標準活動頁、建立雙向連結（Backlinks）、維護全站總目錄（`wiki/index.md`）與演進日誌（`wiki/log.md`）。
3. **公開可瀏覽的現代化成果網頁**：依據沈星回官方代表色「星河紫」搭配星光暖金設計，支援 GitHub Pages 即時瀏覽，提供臨床族群與團體類型雙重維度切換、關鍵字即時檢索，並具備完整展示「分級調適（Grading Down / Up）」及「臨床安全注意事項」的詳細分析抽屜視窗。

## 🚀 成果網頁線上瀏覽與 GitHub 部署教學

### 本地即時預覽：
直接以瀏覽器開啟專案根目錄的 `index.html`，系統內建了完整 32 篇活動的 Fallback 備用資料，無須任何本機伺服器即可離線順暢使用。

### 部署至 GitHub Pages：
1. 將本專案上傳至 GitHub 新儲存庫。
2. 進入儲存庫的 **Settings** -> **Pages**。
3. 在 **Branch** 選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，點擊 **Save**。
4. 等待 1~2 分鐘，即可獲得可公開瀏覽之成果網址：
   `https://<你的GitHub帳號>.github.io/<你的儲存庫名稱>/`

## 🤖 專案規則如何幫助 AI 繼續擴充？

在 `AGENTS.md` 的規範下，未來若要新增一個新團體活動（例如：「高齡長照的星夜懷舊拼布團體」），任何接手的 AI 代理人只要閱讀 `AGENTS.md`，就能清楚執行標準 SOP：
1. **族群與類型邊界確認**：檢驗該活動是否屬於四大族群之一，並標定其團體類型。
2. **結構化寫入**：嚴格依照規定的 5 大核心模組（設計理念與目標、道具與場地佈置、團體流程步驟、Grading Down/Up 分級調適、安全注意事項）輸出在 `wiki/activities/<slug>.md`。
3. **雙向索引串接**：自動在 `wiki/populations/` 和對應的 `wiki/skills/` 補上雙向連結。
4. **目錄與演進同步**：在 `wiki/index.md` 矩陣追加新活動列，並在 `wiki/log.md` 記錄 `[YYYY-MM-DD] ingest | ...`。
5. **前端動態同步**：同步將 JSON 物件寫入 `data/activities.json`，成果網頁（GitHub Pages）無需任何建置與重新打包，即可自動呈現包含卡片、雙向篩選與彈窗詳情的新活動。
