# 執行功能與認知規劃 (Executive Function & Cognitive Planning)

## 1. 能力定義
大腦前額葉掌管之高階認知歷程，包含工作記憶（Working Memory）、抑制控制（Inhibitory Control）、認知彈性（Cognitive Flexibility）、計畫排程（Sequencing）與問題解決（Problem Solving）。

## 2. 臨床介入重點
- **社區精神復健**：依食譜步驟操作、工具清潔先後順序、時間管理與預算控管。
- **高齡長照**：延緩失智認知退化、維持多步驟日常任務完成度。
